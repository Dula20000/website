# 4-Day Lifting Program — Fall 2026

Four sessions, Monday–Thursday. Friday off (travel day), weekend off.

## How the rotation works

Don't assign sessions to fixed weekdays. Keep a **queue** and take the next four each week:

> Push A → Pull A → Legs A → Light/Neck → Push B → Pull B → Legs B → Light/Neck → *(repeat)*

- **Week 1 (Mon–Thu):** Push A, Pull A, Legs A, Light/Neck
- **Week 2 (Mon–Thu):** Push B, Pull B, Legs B, Light/Neck
- **Week 3:** back to the A block, and so on.

If you miss a day, don't skip ahead — just pick up where the queue left off. The A/B split is what gives you the variety: same movement pattern, different exercise, every other week.

Rest: 2–3 min on the heavy compounds, 60–90 s on isolation work.

## Push A — Chest / Shoulders / Triceps

| Exercise | Sets × Reps |
|---|---|
| Flat barbell or machine chest press | 4 × 6–8 |
| Incline dumbbell press | 3 × 8–10 |
| Seated dumbbell shoulder press | 3 × 8–10 |
| Dumbbell lateral raise | 3 × 12–15 |
| Overhead EZ-bar triceps extension | 3 × 10–12 |
| Rope pushdown | 3 × 12–15 |

## Push B — Chest / Shoulders / Triceps

| Exercise | Sets × Reps |
|---|---|
| Incline barbell or machine press | 4 × 6–8 |
| Pec deck or cable fly | 3 × 12–15 |
| Machine shoulder press | 3 × 8–10 |
| Cable lateral raise (one arm at a time) | 3 × 12–15 each |
| Dips (assisted if needed) | 3 × 8–10 |
| Overhead cable extension | 3 × 12–15 |

| Chest-supported row | 3 × 8–10 |

## Pull B — Back / Rear Delts / Biceps

| Exercise | Sets × Reps |
|---|---|
| Pull-ups or neutral-grip pulldown | 4 × 6–10 |
| Front iso-lat row (machine) | 3 × 10–12 |
| Seated cable row (close grip) | 3 × 8–10 |
| Face pull | 3 × 15 |
| EZ-bar curl | 3 × 8–10 |

Both lat exercises land on the same day here — the iso-lat machine and the pulldown hit the lat from different angles, so pairing them beats alternating.

## Light / Neck day (same every rotation)

Low load, high control. This is the day that shouldn't leave you sore.

| Exercise | Sets × Reps |
|---|---|
| Neck flexion (plate on forehead or harness) | 3 × 15–20 |
| Neck extension (face down, plate on back of head) | 3 × 15–20 |
| Neck lateral flexion | 2 × 15 each side |
| Wrist curl | 3 × 15 |
| Reverse wrist curl | 3 × 15 |
| Cable external rotation (rotator cuff) | 3 × 15 each |
| Face pull | 3 × 15 |
| Hanging leg raise | 3 × 12 |
| Cable crunch | 3 × 15 |
| Easy cardio | 15–20 min |

**On the neck work:** start with a folded towel and no weight at all for the first two weeks, then add a 2.5–5 lb plate. Move slowly through the full range — no bouncing, no explosive reps. If you get headaches or any tingling down the arms, stop and get it looked at.

---

## Progression

Add weight when you hit the top of the rep range on every set with clean form. On the compounds that usually means +5 lb upper body, +10 lb lower body. On isolation work, add reps before you add weight.
